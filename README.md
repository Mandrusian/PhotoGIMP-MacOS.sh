# PhotoGIMP macOS Installer

An automated Bash script to install and configure **PhotoGIMP** on macOS for **GIMP 3.x**.

## Prerequisites

1. macOS with [GIMP 3.x](https://www.gimp.org/) installed.
2. Open GIMP at least **once** before running the installer so it generates your default profile.
3. Download the [PhotoGIMP](https://github.com/Diolinux/PhotoGIMP) zip archive to your `~/Downloads` folder.

## How to Use

1. Clone or download the photogimpmac.sh.
2. Open **Terminal** and grant execution permissions to the script:
   ```bash
   chmod +x ~/downloads/photogimpmac.sh
